## Overview

ESG_VM correlates data from **nature-based projects, ESG funds and geospatial sources** to answer questions from investors, NGOs and project managers interested in ESG-oriented investments. This repository is the **entry point** of the program: it hosts the website and links to every part of it.

## Program map

| Part | Repository | What it contains |
|:--|:--|:--|
| 🗄️ Data model | [ESG_VM_Datasets](https://github.com/Moriblo/ESG_VM_Datasets) | Entity-relationship model and catalog of data sources |
| 🔌 Data collection | [ESG_VM_Collectors](https://github.com/Moriblo/ESG_VM_Collectors) | ETL scripts that load each source into the dataset tables |
| 🧠 AI & orchestration | [ESG_VM_Orchestrators_IA](https://github.com/Moriblo/ESG_VM_Orchestrators_IA) | Models, experiments and pipelines versioned with GitHub + DVC |
